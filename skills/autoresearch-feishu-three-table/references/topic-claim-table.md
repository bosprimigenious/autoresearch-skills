# 三期领题表工作流

“三期”表示当前流程中的期次角色，不是可硬编码的表名或数字。实际操作必须先读取当前页面标题、期次字段和 schema；若用户指定的当前期次不同，以用户指定且可验证的权威资源为准。

## 论文进入领题表前

先按 `autoresearch-paper-discovery` 完成论文 canonical ID、官方源码关系、许可证、优化面、baseline/evaluator、资源上界、目标 Harness 和权威查重。候选仍为 `NEEDS_EVIDENCE` 时可以保存草稿，但不能把“草稿已建”写成“领题通过”。查重必须查询当前期次权威题库；旧期表、本地候选池和标题搜索只能辅助。

## 题号核验

1. 列出当前资源的表、视图和字段，找到承担“期次、题号、论文身份、领取状态”语义的真实字段。
2. 按论文 DOI/arXiv ID、规范 URL 和精确标题检索；记录不存在、唯一命中、重复命中必须区分。
3. 若平台生成题号，先创建被允许的最小草稿，再从响应和回读取得题号；不得本地自增或沿用旧题号。
4. 若题号预先存在，核对它所属期次、论文、记录主键和当前状态。任何一项冲突都停止领取。
5. 把当期题号写入私有操作账本，后续两表只从该权威记录传递。

## 领取字段

以下是语义合同，不是固定列名。只填写 live schema 中实际存在且当前角色可写的字段：

- 当前期次与权威题号；
- 论文精确标题、canonical IDs、规范论文链接；
- 官方代码仓、固定 revision 和许可证状态；
- 题目摘要、方法级优化面和主要指标；
- 领取人/协作者字段；
- 领取状态与领取时间；
- 当前期次查重状态及证据引用；
- 资源等级、预计 pilot 上界或流程要求的备注。

人员字段必须使用当前系统的受控人员选择器或当前授权身份，不能把姓名字符串、用户 ID 或邮箱从旧表复制进新表。状态字段必须使用实时枚举；没有与意图等价的状态时停下，不新建近义状态。

## 并发与重复保护

- 写前再次读取目标记录的领取人、状态和更新时间。
- 已由他人领取或状态已推进时，不覆盖；报告 `CONFLICT`。
- 自主提交的新论文若与已有记录 canonical ID 相同，只补证或请求合并，不创建第二题。
- 批量领取必须逐条预演和回读；一条成功不能代表整批成功。

## 权限失败与替代路径

- **资源不可读：** `INCOMPLETE_PERMISSION`。无法证明题号和查重，不做领取写入。
- **能读视图但不能列 schema：** `INCOMPLETE_SCHEMA`。输出语义字段草稿，不按可见列位置操作。
- **能读不能写领取字段：** 生成逐字段草稿、论文证据索引和目标记录别名，交给当前表所有者或题库管理员代填。
- **旧组织身份失效：** 不重新激活、不复用缓存授权。由现任所有者确认权威新表或导出允许迁移的最小记录；在确认前保持 `INCOMPLETE_PERMISSION`。
- **附件或外链不可写：** 先确认当前流程认可的受控存储；只提交稳定证据引用，不把临时下载 capability URL 当长期证据。

## 完成证据

领取完成至少需要：唯一记录、当期题号、论文身份一致、领取字段回读一致、状态枚举正确和写回时间。缺任一项只报告部分完成。
