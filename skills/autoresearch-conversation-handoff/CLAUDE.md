# AutoResearch 对话交接

> 将 AutoResearch 的 Claude、Codex、Cursor 对话、命令输出和外部提交状态整理为可执行交接，区分事实、失败、待办和证据边界。用于总结长会话、换 agent 或收尾归档；不把对话陈述当作已验证事实。

读取可用对话记录、Git 现场、最终包、QA 报告和外部平台页面；对关键结论自己重跑或回读。按 [handoff-schema.md](references/handoff-schema.md) 输出一份当前权威交接，并把旧结论标为历史，不靠“最新消息”覆盖失败证据。

交接必须回答：当前目标、唯一权威包、代码提交、QA 总结、外部提交状态、已验证或未验证边界、失败命令、保留大文件、可删除副本、下一步及完成标准。远端运行还要分别写控制器状态、进程状态、证据是否已拉回、本地哈希是否匹配、操作系统是否关机、云平台是否确认停止计费；SSH 不可达不能单独证明最后一项。涉及凭据时只写位置或轮换建议，不复制密钥。

交接或附件要上传、开源或发给其他团队时，先按 `autoresearch-task-qa` 的隐私与可移植性门禁逐件检查。交接正文使用仓库相对路径或逻辑标识；删除作者 home、主机端口和无需公开的账号信息。私有仓库不能代替隐私检查，飞书/Lark file token 和 capability-style 链接按敏感引用处理。

用户要求“完成”但存在保护范围、平台审核、动态 Harbor 或未上传资产时，明确写部分完成或 NOT READY。
